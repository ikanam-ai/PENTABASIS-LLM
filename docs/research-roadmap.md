# Research roadmap

## Phase 0 — construct specification

**Goal:** freeze a reviewable v0.1 codebook.

- reconcile published Pentabasis formulations
- define ten facets and observable indicators
- document translations in Russian and English
- commission multidisciplinary expert review
- register intended claims and validity tests

**Release criterion:** every facet has a positive definition, inclusion indicators, boundary cases, and primary-source provenance.

## Phase 1 — item-bank pilot

**Goal:** build aligned situations before a large model run.

- write a broad scenario inventory across life domains and social actors
- instantiate observed and preferred variants
- create L1 endorsement, counterbalanced L2 choice, and L3 generation forms
- audit dominance, overlap, reading level, political loading, and translation equivalence
- pilot with a compact multilingual model panel and human reviewers

**Initial sizing target:**

| Component | Pilot target |
|---|---:|
| Scenarios | 150–250 |
| Primary items per level | 30–50 |
| Lens balance | 50% observed / 50% preferred |
| Languages | Russian and English |
| Model packages | 6–10 diverse systems |
| Human cognitive interviews | 20–30 participants |

The final size follows variance, coverage, power, and item-quality results from the pilot.

## Phase 2 — human and scorer validation

**Goal:** create trustworthy reference annotations and distributions.

- stratify L3 outputs by level, facet, lens, language, model family, and response length
- annotate facet evidence, direction, strength, and supporting spans
- measure inter-annotator agreement and adjudicate systematic disagreements
- compare rule-based, encoder, generative, and ensemble scorers
- calibrate score thresholds and uncertainty
- collect matched human responses under the same protocols

**Release criterion:** scorer cards document coverage, reliability, calibration, subgroup error, and examples for every facet.

## Phase 3 — comparative model study

**Goal:** estimate stable and interface-conditioned worldview profiles.

- evaluate open- and closed-weight model families
- repeat runs across system prompts and decoding settings
- test order effects and pairwise consistency in L2
- estimate observed/preferred gaps
- test L1↔L2↔L3 transfer on aligned scenarios
- test self-specificity across interfaces and languages
- compare profiles with human reference distributions

## Phase 4 — framework triangulation

**Goal:** locate PENTA-AI within adjacent value and culture spaces.

- map person-level evidence to Schwartz values
- map culture and institution evidence to GLOBE dimensions
- test expert crosswalks against empirical response geometry
- estimate unique variance carried by Pentabasis levels and facets
- publish uncertainty-aware crosswalk tables

## Phase 5 — release and longitudinal program

**Goal:** maintain a reusable measurement resource.

- versioned dataset and Hugging Face release
- reproducible evaluation package
- public model cards and comparative atlas
- annual or model-generation refreshes
- item-drift and scorer-drift monitoring
- governance process for codebook and translation revisions
